# Repeated physical-fit sampling study, v1

This frozen, development-only study repeats the paired experiment described in
`docs/physical-fit-sampling-pilot-v1.md` with three independently seeded noise realizations for
each combination of radius ratio (0.03, 0.1), impact parameter (0.3, 0.75), exposure (2, 30
minutes), and Gaussian noise level (50, 200 ppm). Thus there are 48 synthetic cases, each fitted
with both the production five-point physical model and the experimental 51-point Simpson model.
The frozen settings and seed are in `configs/physical_fit_repeated.v1.toml`.

Both fits receive the same synthetic light curve, truth-derived initial period, epoch, duration
and depth, two transits, and the same optimizer bounds and loss. The cadence equals the exposure
length. Truth is generated by a 1,001-point integration of the same instantaneous Batman model;
a 501-point resolution check differs by at most 0.00573 ppm, below the predeclared
0.1 ppm tolerance. This is an oracle-initialized fitting study, not a blind search, an independent
physical model, an injection-recovery study, or a study of uncertainty coverage.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  uv run python -m transiteye.evaluation.physical_fit_pilot \
  configs/physical_fit_repeated.v1.toml \
  .transiteye-workspace/remediation/r4-physical-fit-repeated-v1-reproduction
```

All 96 fit attempts are recorded. The current physical refinement returned no fit on eight cases,
and the experimental refinement returned no fit on two; all ten occurred with 30-minute
exposures. A returned failure can mean optimizer nonconvergence or another error; the production
interface does not identify the underlying reason. There were no native warnings or failed truth
reference checks. The command exits nonzero because not all fits were usable. Two-minute exposures
had 24/24 successful fits for each method; 30-minute exposures had 16/24 for the production
method and 22/24 for the experimental method.

The table compares median absolute radius-ratio error **only on cases where both methods produced
usable fits**, and states the number of paired cases. It does not silently count failed fits as
accurate measurements.

| Exposure | Noise | Paired usable cases / attempted | Five-point median error | Simpson median error |
|---|---:|---:|---:|---:|
| 2 min | 50 ppm | 12 / 12 | 0.0000665 | 0.0000909 |
| 2 min | 200 ppm | 12 / 12 | 0.000267 | 0.000258 |
| 30 min | 50 ppm | 6 / 12 | 0.00321 | 0.00175 |
| 30 min | 200 ppm | 8 / 12 | 0.00181 | 0.00153 |

For those same paired cases, median absolute scaled-semi-major-axis errors were respectively
0.0463/0.0373, 0.314/0.318, 3.03/0.848, and 1.72/0.668 for five-point/Simpson. Pairwise selection
excludes up to half of the 30-minute settings, and three repeated draws per geometry do not support
a general performance claim. Per-fit period, epoch, radius, scaled semi-major axis and inclination
errors, time, failures, seeds and diagnostics are retained in `fits.parquet`. They are not the
pipeline's reported trapezoidal depth or duration.

The external workspace `remediation/r4-physical-fit-repeated-v1/` retains the frozen configuration,
backend fingerprint, versions, result table, and source archive. The earlier v1 pilot's original
source snapshot remains in its own workspace; this study adds repeated-case support and changes
future backend fingerprints without changing production fitting. More varied geometries and
cadences, physically independent reference checks, interval coverage, verified real exposure
metadata, and practical runtime remain open before adopting an alternative fitter.
